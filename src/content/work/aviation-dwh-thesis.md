## Aviation Company Data Warehouse

**Jan 2025 – May 2025 · University of Pécs · Pécs, Hungary**

B.Sc. thesis project focused on designing and implementing a comprehensive data warehouse for an aviation company. The project demonstrated end-to-end data warehousing capabilities from requirements gathering through implementation.

### Key Aspects

- Conducted business requirements analysis for aviation-specific KPIs and reporting needs
- Designed dimensional data models (star schema) optimized for flight operations analytics
- Implemented ETL pipelines using Python for data extraction, transformation, and loading
- Built analytical dashboards to visualize key performance metrics

### Technologies

Python, SQL, Dimensional Modeling, ETL, Data Visualization

### Academic Recognition

Thesis project successfully defended, demonstrating practical application of data warehousing concepts learned during the Computer Science B.Sc. program.
